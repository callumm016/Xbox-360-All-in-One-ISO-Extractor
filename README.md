**The easy way to extract Xbox 360 ISOs and transfer games to USB for Aurora.**

## How It Works

1. **Select your game** — Drag and drop an Xbox 360 ISO, ZIP, RAR, 7Z archive, or extracted game folder into the application.
2. **Confirm the game name** — The application automatically identifies the game where possible. You can edit its name.
3. **Choose your USB drive** — Select the connected USB drive or another destination folder.
4. **Click Start Processing** — The application automatically extracts, organises, copies, and verifies your game files.
5. **You're done!** — Your game folder is ready for Aurora on your RGH/JTAG Xbox 360.
